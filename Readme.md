## **DBP - Digtal Banking Platform** ##

**Description**
It's an Web Application which Banks can use to make there Back-Office Work easier. The Application enables the Bank to
manage there Customers, Credit Applications and other Bank related tasks.

**Features**

- Create Customers, Accounts and Cards
- 2FA Verification for User Login
- More Coming Soon

**Tech Stack**

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Docker
- MySQL
- Kafka
- Consul
- Microservices
